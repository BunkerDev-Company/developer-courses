# Презентации для занятий

Библиотека анимированных презентаций для показа на проекторе: главная со списком по папкам,
у каждой презентации — описание, превью и кнопки «Начать» / «Продолжить».

## Запуск

```bash
npm install
npm run dev            # http://localhost:3002 — для подготовки
```

Сайт полностью статический. Собранная версия — быстрее и работает без интернета (шрифты вшиваются при сборке):

```bash
npm run build          # → папка out/
npm start              # раздать out/ на http://localhost:3002
```

## Публикация на GitHub Pages

Workflow уже лежит в `.github/workflows/pages.yml`: пуш в `main` → сборка → публикация.

1. Создать репозиторий на GitHub (для бесплатного Pages — публичный) и запушить проект в `main`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. Через пару минут сайт будет на `https://<логин>.github.io/<репозиторий>/`.

Префикс `/<репозиторий>` workflow подставляет сам (`PAGES_BASE_PATH`). Папка `_notes/` в гит не попадает.
Заметки лектора (клавиша N) — часть сайта, их увидит любой, кто откроет ссылку.

## Управление в презентации

| Клавиша                                  | Действие                                                                                   |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| → / Пробел / PageDown / клик         | дальше: следующий шаг анимации, потом следующий слайд |
| ← / PageUp / клик в левой части | назад                                                                                         |
| F                                               | полный экран                                                                            |
| B                                               | чёрный экран (пауза)                                                               |
| N                                               | заметки лектора                                                                      |
| O                                               | оглавление презентации                                                        |
| T                                               | светлая / тёмная тема                                                             |
| ? или H                                      | подсказка по клавишам                                                           |

Шапка с кнопкой «Все презентации» появляется, когда двигаешь мышью, и прячется сама.
Кликер для презентаций работает (он шлёт PageDown/PageUp).
Ссылка на конкретное место: `/p/backend-inside#12.3` — слайд 12, шаг 3.
